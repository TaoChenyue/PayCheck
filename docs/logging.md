# 日志说明

## 隐私红线（两个工具共同约定）

日志与命令行输出**只记元数据**：文件名、条数、耗时、设备、job id、错误摘要等；
**不记录账单明细**（交易日期/金额/对方账户等隐私数据）。

## 账单工作台日志（paycheck.log）

- **位置**：随库走，即 `<paycheck.db 所在目录>/paycheck.log`（库文件路径见 [workbench.md](workbench.md) 的 `--db`）。
- **格式与轮转**：UTF-8，1MB × 3 份轮转（超 1MB 后生成 `.1` / `.2` / `.3` 备份）。
- **级别**：INFO；管线 logger（`boc_pdf2csv.*`）的页级/文件级日志一并入文件。
- **路径查询**：`GET /api/meta` 的 `log_file` 字段返回当前日志文件路径；启动时终端也会打印「运行日志：<路径>」。
- **记录的关键事件**：
  - 启动：version / db 路径 / convert_dir；
  - 转换任务登记：job id、PDF 数、device / scale / timeout / force；
  - 转换任务开始与结束：status、成功/跳过/失败/停止计数、交易总数；
  - 无 GPU 时的设备确认：等待确认、用户同意用 CPU / 拒绝或停止；
  - 停止请求与已按请求停止；
  - 管线异常：完整 traceback（`exception` 级）；
  - 数据库读写失败。

## boc-pdf2csv 命令行日志

### 控制台输出

- 默认级别 WARNING：控制台只显示进度条、汇总与错误，日常运行不刷屏。
- `--verbose`：控制台级别升到 DEBUG，逐页输出「OCR 块数 → 交易数」、逐文件输出「→ CSV（N 条交易）」，以及跳过/失败明细。

### 文件日志（boc-pdf2csv.log）

每次运行会在**输入目录**写入 `boc-pdf2csv.log`：

- **级别**：INFO；`--verbose` 时升级 DEBUG。
- **格式与轮转**：UTF-8，1MB × 3 份轮转（与工作台 paycheck.log 同款策略）。
- **内容**：管线各阶段日志——扫描到的 PDF 数、跳过原因（同名 CSV 已存在）、每个文件的处理结果（`x.pdf → x.csv (N 条交易)`）、单文件耗时、渲染/OCR 阶段摘要、处理失败的错误信息。
- **边界行为**：输入目录不存在等打不开日志文件的情况不阻断转换，正常按退出码报错。
- 控制台输出行为不变（文件日志只做留存，不往控制台加内容）。

## 排障指引

| 场景 | 看哪里 |
|------|--------|
| 工作台转换任务失败/停止，想知道原因 | `paycheck.log` 中该 job id 的「管线异常」traceback 或结束行 |
| 工作台服务端报错（如数据库写入失败） | `paycheck.log` 对应 ERROR 行 |
| CLI 转换结果不符合预期（缺交易、被跳过） | 输入目录下 `boc-pdf2csv.log` 的逐文件结果与错误行 |
| CLI 单页解析异常 | `--verbose` 再跑一次，看逐页「OCR 块数 → 交易数」与 debug 行 |
| 确认日志是否泄露明细 | 在日志文件中搜索交易日期/金额关键字，应无命中 |
