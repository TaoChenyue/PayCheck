# PDF 转换各选项说明

本文逐一说明 boc-pdf2csv 命令行各选项，以及工作台「转换 PDF」弹窗中对应的高级选项。

## 命令行选项

### `--scale`（渲染倍率）

- 含义：PDF 渲染为图片时的缩放倍率，版面列坐标按该倍率缩放。倍率越高渲染越清晰、解析越稳，但耗时与内存占用越大。
- 默认：`3.0`（标准清晰度，适合大多数对账单）。
- 取值影响：
  - 低配机器可用 `2.0`（更快、占用更小）；
  - 版面列对齐不稳时可尝试 `4.0`（更清晰）。
- 非法值（非数字）：argparse 直接报错退出。

### `--timeout`（单 PDF 超时分钟数）

- 含义：单个 PDF 的处理时限，防止异常文件卡死整个批次。
- 默认：`60` 分钟。
- 行为：到达时限后**中断该文件**——已处理页的结果保留（写入 CSV），剩余页丢弃，继续处理下一个 PDF。
- 非法值（非整数）：argparse 直接报错退出。

### `--force`（覆盖同名 CSV）

- 不带：同名 CSV 已存在时跳过该 PDF（计入汇总「跳过 N 个」），可放心重复运行。
- 带 `--force`：同名 CSV 已存在时覆盖重新导出。

### `--verbose`（详细日志）

- 逐页输出「OCR 块数 → 交易数」、逐文件输出「→ CSV（N 条交易）」、跳过/失败明细；
- 与进度条（tqdm）共存，控制台级别升到 DEBUG；
- 文件日志 `boc-pdf2csv.log` 同步升级为 DEBUG 级（见 [logging.md](logging.md)）。

## 工作台转换弹窗的高级选项

工作台「转换 PDF」弹窗中「高级选项（默认无需修改）」提供与命令行对应的设置：

| 弹窗选项 | 取值 | 对应命令行 |
|----------|------|-----------|
| 渲染精度 | 低 2.0（更快）/ 标准 3.0（默认）/ 高 4.0（更清晰）单选 | `--scale` |
| 超时（分钟） | 输入框，留空用默认 60；填小于 1 的值按最小值 1 处理；非整数报参数错误 | `--timeout` |
| 覆盖同名 CSV | 勾选框，勾选后同名 CSV 已存在时覆盖而不是跳过 | `--force` |

### 转换仅使用 GPU

PDF 转换强制使用 GPU 推理，命令行与工作台均不提供 CPU 选项：

- **命令行**：无 GPU 时转换失败，stderr 报错说明原因（如未安装 GPU 版 paddlepaddle、
  无 NVIDIA GPU、缺 CUDA DLL 等），退出码 3，无 CSV 产物。
- **工作台**：打开「转换 PDF」弹窗时自动探测 GPU，无 GPU 时弹窗顶部警示
  「未检测到可用 GPU（<原因>），PDF 转换不可用」并禁用「开始转换」按钮；
  若绕过前端直接调用接口，任务会直接以 failed 结束，失败原因附在文件错误信息中。

## 常见疑问

- **转换中途能停吗？** 工作台转换任务支持中途停止：页边界协作取消，已完成的文件 CSV 保留、进行中的文件丢弃、任务终态 stopped。命令行无此功能（中断进程即可，已完成的文件产物同样保留）。
- **转换任务进行中能再发起吗？** 工作台会提示已有转换任务（同一时间只跑一个），完成后才能发起新任务。
